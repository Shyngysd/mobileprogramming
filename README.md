Android Group Project — Week 12
Project name: Queue
Description: Queue is a mobile application that shows how crowded popular places are, such as canteens, cafés, gyms and barbershops. Users can report the current situation, and other users can see the information before going to the place.
Members: Marjan, Shyngyskhan, Torekhan
Main features: 
Service Search & Filtering – Search and filter university services.
Queue Monitoring – View queue lengths and estimated waiting times.
Service Details – View service information and availability.
Join Queue – Join a queue and receive a ticket.
Ticket Management – View active tickets and cancel tickets.
User Profile – View user information and profile details.
Local Data Storage – Save tickets and user data locally.
Navigation – Navigate between application screens using Navigation Compose.
